# Ateliê Andressa Lima — Site demonstração

Site demonstrativo responsivo para a confeitaria artesanal Ateliê Andressa Lima.

## Arquivos
- `index.html`: conteúdo e estrutura das seções.
- `style.css`: identidade visual e layout responsivo.
- `script.js`: menu móvel, formulário de encomenda pelo WhatsApp e animações.

## Executar localmente
Abra `index.html` no navegador. O site utiliza imagens hospedadas externamente e fontes do Google Fonts, então esses elementos precisam de conexão com a internet.

## Publicar no GitHub Pages
1. Abra **Settings** deste repositório.
2. Entre em **Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione a branch `main` e a pasta `/ (root)`, depois salve.
5. Aguarde a publicação e abra o endereço informado pelo GitHub.
